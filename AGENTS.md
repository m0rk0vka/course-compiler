# Course Compiler

Start each session by reading [the project log](docs/project-log.md) and the current lesson draft. Check the repo before repeating research or claiming something was rendered.

This project adapts MIT distributed systems for personal study. Keep narration, captions and discussion prompts in English. Aim for short episodes with a clear stopping point and one optional prediction question. Link to the original materials and the Go lab.

Before marking an episode ready, check its technical claims against primary sources. Record the source version, section or verified timestamp. Review the order of events in any diagram and solve questions before publishing them. Track transcript, audio and frame verification explicitly.

Update the project log when decisions, sources, tools or deliverable status change. Distinguish researched tools from tools run on this project. Link actual artifacts and record the next concrete step. Keep raw transcripts and source media out of the repository unless their redistribution is authorized.
